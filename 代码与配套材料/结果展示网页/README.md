# 结果展示网页

用于课堂展示国家双碳政策文本分析的流程、热力图、方法对照、词数实验与原文案例。

## 打开方式

在项目根目录双击“打开结果展示网页.cmd”，也可双击本目录“打开网页.cmd”或用浏览器打开index.html。正常展示无需联网、Python或显卡；请保留整个文件夹。

如果浏览器限制本地页面，可在本目录执行 `python serve.py`，再访问 `http://127.0.0.1:8765/`。服务仅监听本机，按Ctrl+C停止。

## 页面内容

- 国家关系：国家／教师六组，主集／加入扩展集，四种表征及文章／事件视图；可点击矩阵查看近邻、限定共同国家范围、显示数值、导出矩阵。
- 数据与流程：原始文档、主扩事件记录、各国覆盖与CM-PACE评分的作用。
- 方法评价：23对框内随机与14对专项难例分别展示，主题和措施分别计算Spearman。
- 词数实验：50、100、200及全部有效词项的截断与近邻变化；可用滑块查看逐整数K结果。
- 原文案例：主题措施接近、方向相反、同一战略不同版本的实际材料及来源。

## 数据与解释

采用项目“结果”目录中的完整冻结结果：代码版本G20-GROUP1-20261027.final，输入版本CLASSROOM-INPUT-CENTER-20261027.4。网页读取这些结果的展示副本，不执行清洗、模型训练或重新编码。原结果变化后，需重新核对并更新展示副本。

原始TXT为2989篇；保留内容涉及1728篇原始文章；去重事件记录5965条（主782、扩展5183）。有效文章内政策文本为主集597条、主加扩1868条，材料可用国家／地区分别13和18个。事件、来源组、分析文本与独立政策是不同单位。

最小K为主集52（条件性95%区间47—64）、主加扩144（132—157）：标准是至少95%的文本保留至少99%的TF-IDF权重，依赖当前分词、词表、IDF与来源组重抽样条件，不是语义正确性保证。

方法对照使用大模型辅助参考标签；独立真人语义验收尚未完成。Spearman衡量参考排序一致性，不是整批准确率、召回率或F-评价。不能据小样本差异宣布某模型普遍最佳。余弦相似度反映历史文本主题和措施表述接近程度，不能解释为政策一致百分比。

## 文件说明

index.html为页面；style.css为样式；app.js为交互与图表；data.js为离线数据；data.json为可读数据；csv为来源表副本；data_manifest.json保存原结果文件校验值。原始来源位于项目“结果”目录，可按相对文件名追溯。

本目录仅收录展示运行文件、数据和说明；设计稿、生成工具、临时测试文件与工作日志不纳入展示目录。整理核验记录保存在项目“核验”目录。
