# 核心函数与课堂代码阅读顺序

从`运行实验.py`进入，按五个模块讲解即可；完整辅助函数位置见`函数索引.csv`。内部清洗规则是一套当前仍被调用的规则引擎，不是多套旧版本流程。

|函数|所在文件（src下）|输入|输出|解决的问题|
|---|---|---|---|---|
|run|data_cleaning.py|原始ZIP、配置、明确固定处置|主集/扩展事件、分国CSV、原文映射|完整清洗与最终输入一致性|
|load_archive|cleaning_rules/读取与规范化/ingest.py|课程ZIP|文档、元数据、异常列表|编码、路径和元数据关联|
|clean_document|cleaning_rules/读取与规范化/cleaning.py|原文、标题|规范正文、删除证据|网页噪声与清理追溯|
|to_simplified|cleaning_rules/读取与规范化/text_normalization.py|分析文本|简体分析副本|繁简表达一致|
|source_units|cleaning_rules/pipeline.py|文档、固定处置跨度|源文本单元|句界切分与已处置部分排除|
|process_record|cleaning_rules/pipeline.py|单元、全文、文档和组件|一个或多个带分流记录|内容、角色、状态的完整规则链|
|ScopedAttribution.relation|cleaning_rules/主体与国家归属/scoped_roles.py|句内原文、位置|施策角色及动作|区分施策主体、对象和合作关系|
|ScopedAttribution.country_decision|cleaning_rules/主体与国家归属/scoped_roles.py|当前句、全文、元数据|国家、依据、分数、连接|角色优先并补政策指代|
|density_context|cleaning_rules/主体与国家归属/scoped_roles.py|当前单元、政策锚点|有边界的政策窗口|D只统计相关政策上下文|
|score_candidates|cleaning_rules/主体与国家归属/optimized_attribution.py|实体、动作、连接、来源及参数|候选国的E/P/D/M/S|有证据约束的竞争排序|
|policy_state|cleaning_rules/主体与国家归属/national_scope.py|政策事实|初始动作状态|区分公布、执行、取消、建议等；后续规则继续修正|
|aggregate_events|cleaning_rules/政策归并与导出/exports.py|事件出现记录|精确归并事件|同事实关联来源；不声称所有独立政策已经识别|
|run_features|text_features.py|最终事件与来源|词元、原权重、四种K稀疏矩阵|统一分词及基线表征|
|verify_source / prepare_source|text_features.py|事实、原文跨度|校验结果、映射|拆分后仍能追溯原文|
|build_documents|text_features.py|事件、原文、来源索引|文章/事件视图及映射错误|确保分析文本来自保留事实|
|Tokenizer.tokenize|text_features.py|片段文本|词元及过滤原因|词典、停用词、语义保护规则|
|transform_tfidf|text_features.py|词元、冻结词表与IDF|规范向量及未规范权重|对数TF与平滑IDF|
|select_top_k|text_features.py|原始权重、K|Top-K规范向量、诊断|按不同词项权重选词|
|run_vectors|word_vectors.py|同一词元、权重及模型资源|加权fastText、BGE、去均值|稀疏与稠密表示互补|
|token_windows / encode|word_vectors.py|完整文本、BGE|重叠块与512维文本向量|长文本完整覆盖；属于推理而非训练|
|aggregate_country_vectors|country_analysis.py|向量、元数据、抽样权重|国家向量、覆盖及无效行|来源组等权、共同材料保留|
|cosine_country_matrix / rank_country_similarities|country_analysis.py|国家向量|余弦矩阵、近邻|缺失不填零，排名排除自身|
|grouped_bootstrap|country_analysis.py|向量、元数据、次数和种子|各次国家相似度及描述区间|按来源连通组抽样，保留重复抽取次数|
|run_periods|country_analysis.py|可验证日期和当前文本|分期覆盖及相似度|日期明确子集对照|
|run_evaluation / rho|evaluation.py|固定参考与当前预测|主题/措施Spearman|相同有效配对公平比较；未知不填零|
|word_count_experiment|evaluation.py|原TF-IDF权重与来源组|最小K、覆盖曲线、条件区间|明确回答词数问题|
|grouped_bootstrap|evaluation.py|逐文本所需K、组、分层、种子|10,000个重抽样K|与国家相似度重抽样同名但任务不同|
|verify / freeze|verification.py|完整本轮结果|检查明细、资源和结果哈希|数量、ID、向量、国家文件与原口径重现|

`fit_tfidf`保留为重新拟合的基础接口，但当前复现实验使用冻结词表和IDF；直接改变拟合范围会改变比较口径，不能套用现有参考成绩。
