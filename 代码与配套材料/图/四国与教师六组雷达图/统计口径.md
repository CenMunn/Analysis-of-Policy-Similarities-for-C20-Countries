# 统计口径

分析输入为主集文章政策集合 article_policy/main/元数据.csv。国家由清洗后的施策国家字段确定，不按原始文件夹决定。教师六组映射为：德意=德国、意大利；法国；美国；日韩沙特印尼=日本、韩国、沙特阿拉伯、印度尼西亚；英国；中国汇总=中国。

各项为至少命中相应关键词的有效文本数 / 该国或组的有效文本总数，同一文本可命中多个主题。六组中多国材料按文本合并，组内国家不是等权，材料较多的国家对结果影响较大；若同一文本包含同组多个参与国，同组只计一次，跨组共同文本可在不同组分别计入。

关键词见主题占比CSV；其中“可再生能源与电力”也包含煤电、核电等电力词语，不能解释为可再生能源比例。关键词不区分是否定、政策方向和状态，未命中不代表不存在。去重和主题识别仍有不确定性。该图不是政策强度、政策一致性或国家政策完整结构，也不同于来源组等权的国家相似度热力图。
