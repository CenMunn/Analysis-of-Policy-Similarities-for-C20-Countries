## 环境与运行

建议Windows、Python 3.12。依赖见requirements.txt；首次安装依赖需要网络。原始数据、冻结词表和运行资源均已包含，默认流程不联网请求评分。

双击“一键运行.cmd”，或在本目录运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B 运行实验.py --mode classroom
```

课堂模式重新读取原始ZIP并规范化文本，复用经校验的识别中间账本，重新执行末端处置、分词、权重、加权fastText、聚合、评价与绘图。BGE按文本SHA复用冻结编码。该模式适合课堂演示；复用环节会在控制台明确显示，不能称为重新执行全部识别和编码。

完整规则识别：

```powershell
.\.venv\Scripts\python.exe -B 运行实验.py --mode full --output 完整运行新结果
```

连同本地BGE重新推理：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-bge.txt
.\.venv\Scripts\python.exe -B 运行实验.py --mode full --reencode-bge --output 完整含编码新结果
```

BGE自动使用可用CUDA，否则使用CPU。生成向量属于冻结模型推理，本项目未微调BGE。完整模式明显慢于课堂模式。

每次默认新建“演示输出/时间戳”目录，不覆盖既有结果。输出目录已存在时请换用新的目录名。模型或检查点校验失败时，应检查是否完整解压，不要跳过校验。此包用于复现当前冻结课程语料；新增数据不能直接沿用已有固定处置和编码。

## 代码结构

| 模块 | 作用 |
|---|---|
| src/data_cleaning.py | 读取、清理、内容识别、主体与层级、状态及事件导出 |
| src/text_features.py | 统一词元、TF-IDF、Top-K与文章/事件视图 |
| src/word_vectors.py | TF-IDF加权fastText、BGE和去均值对照 |
| src/country_analysis.py | 来源组等权聚合、国家及教师六组相似度与对照 |
| src/evaluation.py | 同口径参考配对评价、最小K及来源组重抽样 |

共用读写、绘图和检查位于src内；清洗规则按功能存放于src/cleaning_rules下的中文子目录。具体函数见“说明/函数索引.csv”。

## 结果与口径

代码版本G20-GROUP1-20261027.final；分析输入CLASSROOM-INPUT-CENTER-20261027.4。

- 原始TXT：2,989篇。
- 最终去重事件记录：5,965条，其中主分析候选782条、扩展候选5,183条；尚不能统称独立政策。
- 有效文章政策文本：主集597条，主集加入扩展后1,868条；分别有13和18个国家/地区具备有效材料。
- 教师六组：德意、法国、美国、日韩沙特印尼、英国、中国汇总；按清洗后的施策国家映射。
- K=50、100、200、全部，表示按权重保留的不同有效词项数。BGE使用完整文本，不虚构K配置。
- “95%文本保留99%权重”标准下，最小K为主集52、主加扩144；条件性95%区间分别为47—64和132—157。它们是当前语料的压缩指标及重抽样结果，不是语义正确率的保证。

主集与扩展集分别保存；来源推定及不确定性不能隐去。余弦相似度不是政策一致百分比，主题接近也不保证方向、状态或时期相同。参考配对的主题与措施Spearman分开报告，标签来源为大模型辅助参考及整体确认，独立真人逐条验收尚未完成。整批正式准确率P、召回率R、F-评价仍为尚未测定；不使用早期开发高分替代。

包内“结果”保留适合查阅的最终表格和证据，不包含全部大体积中间向量。运行后会完整生成词元、稀疏矩阵、词向量、国家关系和评价结果。原文追溯从“结果/01_数据清洗/最终分析输入/追溯/来源索引.csv”及其相对正文路径读取；事件CSV中的列表与嵌套字段采用JSON字符串。
